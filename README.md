## Blackjack

An interactive text-based Blackjack simulator, designed to run in Jupyter Notebook. One (1) user plays against a dealer (computer). All standard Blackjack rules are applied, but users are only currently allowed to make bets, and “hit” or “stand” on their turn. 

This project served to develop my object-oriented programming skills, input validation and error handling, game loop and state management

Using python code, I:

- Implemented object-oriented design using Card, Deck, and Hand classes
- Built full game loop with input validation and state management
- Designed dynamic ‘Ace’ handling (1 or 11) to optimize hand values
- Implemented standard Blackjack rules (dealer hits ≤16, stands ≥17)
- Added betting system with correct payouts (3:2 blackjack, 1:1 wins, push handling)
- Enhanced user experience with screen clearing and timed delays for realistic pacing/dramatic effect

Future improvements:
- Add more Blackjack features such as splitting hands and doubling down
- Implement a graphical user interface
